# Parking Spot Finder

A production-quality full-stack web application to help users find nearby parking spaces using their current location.

## Project Structure
- `/frontend` - React + TypeScript + Vite SPA.
- `/backend` - Node.js + Express + TypeScript API.

## How to Run Locally

### 1. Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
